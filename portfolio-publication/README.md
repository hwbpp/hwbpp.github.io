# Hugo Wahyu Bagas Putra Pratama — Portfolio

Personal portfolio covering data analytics, business intelligence, data engineering, and selected software projects.

## Technology

Static HTML, CSS, and vanilla JavaScript. No dependencies or build step are required. Google Fonts supplies the Inter typeface.

## Structure

- `index.html`: homepage and contact information
- `about.html`: profile
- `projects/`: six project case studies
- `assets/`: styles, scripts, images, and favicon

## Preview locally

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Deployment

Compatible with GitHub Pages. Publish the repository root from the `main` branch. Relative asset and navigation paths support both an account site and a project site.

## Updating

Edit HTML for content, `assets/css/main.css` for styling, and `assets/js/main.js` for interactions. Check all pages on desktop and mobile before publishing changes.
